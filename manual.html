1

화면 구성

업비트 탭

빗썸 탭

①
헤더 로고 · 버전 표시. 오른쪽에 라이트/다크 모드(🌙), 설정(⚙), 관리 버튼, 알람 추가(+) 버튼.
②
거래소 탭 업비트 / 빗썸 탭 전환. 해당 사이트 열면 자동 전환. 활성 탭은 컬러 표시.
③
알람 목록 코인 티커 · 한글명 · 현재가 표시. 행 오른쪽 ＞ 클릭으로 조건 확인 및 수정.
④
알람 행 하단 조건(이상/이하) · 목표가 표시. 토글로 활성화/비활성화. ✕로 삭제.
⑤
관리 버튼 헤더 우측 관리 버튼 → 전체 알람 편집 모드 (메모, 순서 변경 등).
2

알람 추가하기

1
거래소 탭 선택

상단 탭에서 업비트 또는 빗썸 선택. 해당 사이트를 열고 있으면 자동 전환.

2
코인 검색

코인명(한글/영문) 또는 티커로 검색. 예: 비트 BTC 이더. 초성 검색 지원 (예: ㅂㅌㅋ).

3
목표가 입력

알람을 울릴 목표 가격을 원화로 입력. 쉼표(,) 없이 숫자만 입력.

4
조건 선택

이상 : 현재가가 목표가 이상이 되면 알람
이하 : 현재가가 목표가 이하가 되면 알람

5
비고 입력 (선택)

메모를 남기면 알람 목록과 알람 발동 시 토스트에 빨간색으로 표시됩니다.

6
+ 알람 추가 버튼 클릭

목록에 추가되어 즉시 감시 시작.

💡 + 버튼 클릭 시 코인 입력란에 자동으로 포커스됩니다. 클릭 없이 바로 타이핑하면 됩니다.
💡 빗썸에서 코인 검색 시 한글 이름이 없는 코인은 티커(영문)만 표시됩니다.
3

알람 관리

✏️ 수정

알람 행의 수정 버튼 클릭 → 목표가 또는 조건(이상/이하) 변경 후 확인.

🗑 삭제

삭제 버튼 클릭 → 알람 영구 제거. 되돌릴 수 없으니 주의.

⏸ 비활성화 / 활성화

비활성화 클릭 시 알람이 일시 중단. 다시 활성화 클릭 시 감시 재개.

🔔 알람 발동 후 상태

조건 충족 시 알람이 울리고 자동으로 비활성화. 설정된 재활성화 시간 후 다시 감시 재개.

📍 현재 페이지 코인 우선 표시

현재 열려 있는 코인 거래 페이지와 일치하는 알람이 목록 최상단으로 자동 정렬되고 📍 배지로 표시됩니다.

4

알람 내보내기 / 가져오기

📤 내보내기

팝업 하단 내보내기 버튼 → JSON 파일로 저장. 현재 보고 있는 거래소(업비트 또는 빗썸)의 알람만 저장.

📥 가져오기

가져오기 버튼 → JSON 파일 선택. 파일 내용을 보고 업비트/빗썸 알람 자동 판별 후 해당 스토리지에 저장.

💡 기기 변경이나 백업 시 활용하세요. 업비트 알람은 업비트로, 빗썸 알람은 빗썸으로 자동 분류됩니다.
⚠ 가져오기 시 기존 알람이 모두 덮어씌워집니다.
5

설정 — 알람 소리 · 볼륨

팝업 우상단 ⚙ 설정 버튼 → 알람 소리 섹션

설정 화면

🎵 효과음 종류

  • 없음 — 소리 없이 토스트만 표시
  • 팡파레 — 경쾌한 팡파레 소리
  • 레벨업 — 게임 레벨업 효과음
  • 타다 — 짧고 밝은 효과음
  • 딩3회 — 딩 소리 3번
  • 승리 — 승리 팡파레
  • 동전소리 — 동전 떨어지는 소리
  • 뚝배기 — 뚝배기 소리
  • 마이너스 — 마이너스 효과음

🔊 볼륨

슬라이더로 0~100% 조절. 슬라이더를 움직이는 즉시 자동 저장되고 미리듣기에도 바로 반영됩니다.

6

설정 — 재활성화 방식

알람이 한 번 울린 뒤 언제 다시 감시를 시작할지 설정합니다.

즉시

알람 발동 직후 즉시 재활성화. 가격이 계속 조건을 충족하면 반복 알람.

30분 후

알람 발동 30분 후 자동 재활성화.

1시간 후

알람 발동 1시간 후 자동 재활성화.

직접 입력 기본값

원하는 분(分) 단위로 입력. 기본값 1분. 예: 5 입력 시 5분 후 재활성화.

💡 단타 트레이딩에는 즉시 또는 직접입력 1분 추천. 장기 모니터링에는 1시간 추천.
7

알림 동작 방식

📡 가격 체크 주기

  • 업비트 — 1.5초 간격으로 실시간 가격 체크
  • 빗썸 — 2초 간격으로 실시간 가격 체크

🔔 알람 발동 시 동작

  1. 화면 상단에 토스트 메시지 표시 (코인명, 조건, 현재가)
    · 비고가 있으면 토스트 하단에 빨간색으로 표시
    · 토스트 클릭 시 해당 코인 거래 페이지로 이동
  2. 알람 소리 재생 (설정된 효과음)
  3. 브라우저 알림 표시 (알림 권한 허용 시)
  4. 해당 알람 자동 비활성화 → 설정된 시간 후 재활성화

⚡ 동작 조건

  • 업비트(upbit.com) 또는 빗썸(bithumb.com) 탭이 열려 있어야 동작
  • 탭이 백그라운드(숨김)여도 감시 계속
  • 브라우저 완전 종료 시 알람 중단
⚠ 거래소 탭을 닫으면 해당 거래소 알람이 동작하지 않습니다.
