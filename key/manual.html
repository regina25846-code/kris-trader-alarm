화면 구성

빗썸 탭
①
헤더 로고 · 버전. 우측에 🌙 다크/라이트 모드, 🔊 사운드 설정, ⚙ 일반 설정 버튼.

2

단축키 추가 · 수정 · 삭제

1
조합키 선택

첫 번째 드롭다운에서 Alt · Ctrl · Shift · 없음 중 선택.

2
키 선택

두 번째 드롭다운에서 키 선택 (숫자 0~9, 영문자 a~z 등).

3
명령어 선택

세 번째 드롭다운에서 실행할 명령어 선택. 일부 명령어는 수량/가격 직접 입력 가능.

4
저장

하단 저장 버튼 클릭. 저장하지 않으면 변경사항 유실!

💡 삭제는 각 행 우측 삭제 버튼. 삭제 후 저장해야 반영됩니다.
⚠ 같은 조합키+키 조합을 두 행에 설정하면 마지막 저장된 것만 동작할 수 있습니다.

사운드 설정

헤더 우측 🔊 버튼 클릭 → 사운드 설정 모달

사운드 설정 화면

ON / OFF

매수·매도·취소 시 효과음 재생 여부. OFF 시 무음.

볼륨 슬라이더

0~100% 조절. 슬라이더 우측에 현재 % 표시.

효과음 종류

  • sound1/2/3 — 웹오디오 합성음
  • 동전소리 — 동전 효과음
  • 뚝배기 — 뚝배기 효과음
  • 마이너스 — 마이너스 효과음
  • custom — 직접 파일 업로드

듣기 버튼으로 미리 청취 가능.

업비트 설정

🔒 주문 확인창 자동 승인

ON 시 단축키 실행 후 나타나는 주문 확인 팝업을 자동으로 승인. 빠른 매매에 유용.

⚠ 실수로 잘못된 주문이 실행될 수 있으니 주의하세요.

📐 레이아웃 토글 (업비트 전용)

레이아웃 변경 시 차트·매수매도창·호가창이 브라우저 너비에 맞게 자동 반응형 배치됩니다. 1920px 이상 모니터에서 매수매도창·호가창이 최대 폭으로 확장되며, 그 이하에서는 화면에 맞게 자동 조절됩니다.

세로 반응형 설정

  • 세로 반응형 OFF (기본) — 차트 높이를 직접 px로 입력. 기본값 451px.
  • 세로 반응형 ON — 차트 높이가 브라우저 창 높이에 맞게 자동 확장.
6

설정 내보내기 / 가져오기

📤 내보내기

⚙ 설정 → 내보내기 버튼 → JSON 파일로 저장. 업비트 + 빗썸 단축키 설정 전체 저장.

📥 가져오기

가져오기 버튼 → 내보낸 JSON 파일 선택 → 단축키 설정 복원.

💡 단축키 및 설정 옵션은 브라우저에 자동으로 저장됩니다. 다른 PC로 이전하거나 설정을 공유할 때만 내보내기/가져오기를 사용하세요.
⚠ 가져오기 시 현재 설정이 덮어씌워집니다.

빗썸 탭 바로가기 (1~7)

빗썸 거래 화면의 탭을 숫자키로 바로 전환할 수 있습니다.
