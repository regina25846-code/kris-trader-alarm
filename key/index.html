v1.1.3 2026-05-10 ⬇ 다운로드
레이아웃 반응형 적용 — 차트·호가창이 브라우저 창 크기에 맞게 자동 확장

📦 업데이트 방법

  1. 위 다운로드 버튼으로 zip 파일 받기
  2. 기존 확장 프로그램 폴더에 압축 해제 (파일 덮어쓰기)
  3. 브라우저 주소창에 입력 후 접속
      • 크롬: chrome://extensions
      • 웨일: whale://extensions
  4. 확장앱 관리자 목록에서 Kris Trader Key를 찾아 새로고침(↺) 버튼 클릭
