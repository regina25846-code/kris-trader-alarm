⚠ 업데이트 전 필독 (v2.0.7 이하 사용자)
  • 업데이트 전 팝업 → ⚙ 설정 → 내보내기로 알람을 백업해두세요.
  • v2.0.7 이하에서 처음 업데이트하는 경우 기존 알람이 초기화돼요. (v2.0.8 이후부터는 유지)
  • 확장 프로그램 폴더 위치를 변경하면 알람이 초기화될 수 있어요. 폴더는 항상 같은 위치에 두세요.

📦 업데이트 방법

  1. 위 다운로드 버튼으로 zip 파일 받기
  2. 기존 확장 프로그램 폴더에 압축 해제 (파일 덮어쓰기)
  3. 브라우저 주소창에 입력 후 접속
      • 크롬: chrome://extensions
      • 웨일: whale://extensions
  4. 확장앱 관리자 목록에서 Kris Trader Alarm을 찾아 새로고침(↺) 버튼 클릭
